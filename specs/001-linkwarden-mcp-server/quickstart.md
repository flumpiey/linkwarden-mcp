# Quickstart: Linkwarden MCP Server

Validation guide for feature `001-linkwarden-mcp-server`. Implementation tracked in `tasks.md` (generated by `/speckit-tasks`).

## Prerequisites

- Python 3.13+
- [uv](https://docs.astral.sh/uv/) installed
- Linkwarden instance with API token (for manual smoke test only)

## Install (local dev)

```powershell
cd E:\Development\linkwarden-mcp
uv sync --dev
```

## Configure (read-only smoke)

```powershell
$env:LINKWARDEN_URL = "https://your-instance.example.com"
$env:LINKWARDEN_TOKEN = "your-token"
# Write/delete flags unset → read tools only
```

## Run server

```powershell
uv run linkwarden-mcp
```

Or via uvx after publish:

```powershell
uvx linkwarden-mcp
```

## MCP client config (Cursor example)

```json
{
  "mcpServers": {
    "linkwarden": {
      "command": "uvx",
      "args": ["linkwarden-mcp"],
      "env": {
        "LINKWARDEN_URL": "https://your-instance.example.com",
        "LINKWARDEN_TOKEN": "your-token"
      }
    }
  }
}
```

## Automated validation (no live instance)

```powershell
uv run pytest
```

Expected: all tests pass with zero env credentials set.

Key offline scenarios (see `tests/`):

| Test | Proves |
|------|--------|
| Denylist blocks `/api/v1/tokens` | SC-003 |
| Invalid permission aborts startup | SC-004 |
| Bulk cap refusal names both counts | SC-006 |
| Overview sums collection `_count.links` | FR-017 invariant |
| Tag pagination → `tags_partial` or full cursor | FR-017 |
| `read_link_content` prefers textContent | FR-014 |
| merge_tags requires DELETE permission | FR-016 |

## Manual smoke (read-only)

1. Start server with url + token only
2. `list_tools` → 6 read tools, 0 write/delete
3. `get_library_overview` → totals, empty collections, Unorganized size
4. `search_links` with collection name "Homelab"
5. `read_link_content` on a preserved link → plain text

## Manual smoke (write, optional)

```powershell
$env:LINKWARDEN_WRITE = "1"
$env:LINKWARDEN_MAX_BULK = "25"
```

1. `save_link` to existing collection by name → no duplicate collection
2. `queue_archive` → message says queued, not completed
